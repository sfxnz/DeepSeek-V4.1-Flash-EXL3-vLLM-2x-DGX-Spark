fusion-host (k3 round 3): serve-arm validation plan
=====================================================
Not run here: the stage rules forbid serves while spark1's GPU runs the requant and
while microbenches run. Everything below is for the integration/serve phase. The 7
envs are all default 0 (run.sh FORWARD_ENVS), so A boots are the stock paths.

0. Preconditions (all must hold; otherwise the arm is invalid)
--------------------------------------------------------------
- The requant is finished: `docker ps --format '{{.Names}} {{.Image}}'` on spark1 shows
  no dsv41-requant, and `ssh spark2 docker ps` shows no GPU container.
- Both GPUs clean: `nvidia-smi pmon -c 1` (spark1) and `ssh spark2 nvidia-smi pmon -c 1`
  list only Xorg / gnome-shell (type G). The Chromium GPU process on spark1 belongs to
  another session: ask the user to close it, never kill it. With it present, rank 0
  straggles (profile section 5, item 10) and no number from that boot is usable.
- The round-34 serve (if up) is stopped with ./stop.sh from ITS worktree
  (.worktrees/perf-review-0924); that worktree's docker/patch is not touched.
- Boot from a checkout that contains the fusion-host commits (k3/fusion-host, or the
  integration branch that merged it). run.sh mounts that checkout's docker/patch on the
  head (PATCH_DIR) and scp's it to spark2 (~/.cache/dsv41-patch), so no image rebuild is
  needed: engram_native.c is compiled by gcc inside the container at first use
  (/tmp/dsv41-native, content-hash name) and the Triton kernels JIT at the first eager
  call.
- Image: IMAGE=dsv41-flash-exl3-sm121:canonical-e13 on both nodes (what every check ran
  on). On any other image (e14) first run section 4 on that image: the source rewrites
  (moe_prep_fused, swa_meta_fused) use verbatim anchors pinned from e13 and print their
  LOG_DISARMED line on drift, which fails AUDIT=strict.
- `free -h` on both nodes before boot: MemAvailable >= 12 GiB (ARMS step 4).
- Gate first: `python3 -m unittest discover -s tests -q` (0 failures, 0 errors) and
  `python3 kit/render.py --check` (exit 0) on the checkout being booted.

1. Arms (ABAB, four numbers on every boot; ARMS.md)
--------------------------------------------------
Baseline envs = whatever the integration branch ships as defaults (round 34:
DSV41_ENGRAM_WILLNEED=1 DSV41_STREAM_FEED=1 DSV41_WOA_PREPACK=1 DSV41_DSPARK_SPARSE_MARKOV=1).
A and every B differ only by the envs listed.

  arm  envs added to A                                       projected ms/step c=1 / c=2
  A    (none)                                                 0 / 0
  ALL  DSV41_ENGRAM_NATIVE_STAGE=1 DSV41_ENGRAM_EARLY_HASH=1   -2.75..-3.00 / -4.0..-4.3
       DSV41_ATTN_T2R_DEDUP=1 DSV41_SWA_META_FUSED=1          (4.4-4.8% of 62.8 ms c=1;
       DSV41_MOE_PREP_FUSED=1 DSV41_CANDIDATE_MASK_BOUNDED=1   ~4.6-5.0% of ~86 ms c=2)
       DSV41_INDEXER_WP_GEMV=1
  B1   DSV41_ENGRAM_NATIVE_STAGE=1 DSV41_ENGRAM_EARLY_HASH=1   -1.34..-1.46 / -2.1..-2.3
  B2   DSV41_ATTN_T2R_DEDUP=1 DSV41_SWA_META_FUSED=1          -0.65..-0.70 / -0.75..-0.80
  B3   DSV41_MOE_PREP_FUSED=1 DSV41_CANDIDATE_MASK_BOUNDED=1   -0.72..-0.84 / ~-1.2
       DSV41_INDEXER_WP_GEMV=1

Order: A, ALL, A, ALL first. ALL is a deliberate exception to one-lever-per-boot: all 7
are bit-exact (no numerics or acceptance change by construction) and each one alone is
below the boot-to-boot spread (identical configs measured 27.40 / 26.13 / 28.01 tok/s).
If ALL passes the gate, attribute with A, B1, A, B1 (the only set expected to clear the
noise alone), then B2 and B3 the same way; a set that does not show its projected size
comes out of the bundle and gets a profile-window check (section 3) before any retry.
Optional B1a = DSV41_ENGRAM_NATIVE_STAGE=1 alone (early hash is a further -0.17 c=1).

2. Per boot (ARMS order; record the exact env line and argv in the arm notes)
--------------------------------------------------------------------------------
  cd <checkout>
  ./stop.sh                                     # both nodes; confirm no GPU containers
  env AUDIT=strict IMAGE=dsv41-flash-exl3-sm121:canonical-e13 <baseline envs> <arm envs> ./run.sh
  # run.sh exits non-zero if a gated patch did not print its LOG_ENGAGED line on a rank
  for h in local spark2; do                     # engagement, both ranks, every armed lever
    c='docker logs dsv41-flash-exl3 2>&1 | grep -E "engram native stage self-check bit-exact|engram early hash matches the stock hash|token->request map dedup across KV-cache groups armed|moe prep fused self-check bit-exact|candidate mask bounded self-check bit-exact|indexer weights_proj GEMV self-check bit-exact|swa metadata fused self-check bit-exact|DISABLED|lever is OFF|FAILED"'
    [ $h = local ] && bash -c "$c" || ssh spark2 "$c"
  done
  free -h; ssh spark2 free -h                   # >= 12 GiB before smoke
  python3 smoke_chat.py                         # non-empty content; 323 for 17*19
  python3 smoke_vision.py                       # no HTTP 400 "is not a multimodal model"
  free -h; ssh spark2 free -h                   # >= 8 GiB after smoke
  python3 tools/measure_lail_prose.py --runs 10 # fresh L.A.I.L before any c=2 traffic
  tools/four_numbers.sh --arm fh-<arm>-<boot#>  # prose 9x, pp_warm/pp_novel 8k/32k, MemAvail,
                                                # L.A.I.L 3x, prose_long c=1/c=2, warm-prefix,
                                                # env digest per rank, disarm scan
  python3 benches/e2e.py                        # exit 0
  python3 tests/quality_eval.py --quick \
    --baseline results/2026-09-24-review/quality-baseline/quick.json \
    --out results/<arm-dir>/quality_quick.json  # exit 0 (ALL and each B set, once per set)
  tools/disarm_scan.sh                          # exit 0: no LOG_DISARMED on either rank after
                                                # all traffic (the verify paths ran on real
                                                # batches: native 8, early 8, moe 16, mask 4,
                                                # wp 8, swa 8 calls; all must stay armed)
  ./stop.sh

Expected engagement per rank with ALL: the 7 lines above once each (the native stage
line says "2 tables"), 0 DISABLED / "lever is OFF" / FAILED lines.

3. Kernel-level confirmation (separate ALL boot, one profile window; ARMS: profiling is
   its own gated step)
------------------------------------------------------------------------------------
  env AUDIT=strict DSV41_ENGRAM_CENSUS=1 <baseline envs> <ALL envs> \
      EXTRA_ARGS='--profiler-config {"profiler":"torch","torch_profiler_dir":"/tmp/dsv41-traces"}' ./run.sh
  python3 smoke_chat.py && python3 tools/measure_lail_prose.py --runs 3
  docker logs dsv41-flash-exl3 2>&1 | grep '\[native-census\]' | tail -3   # both ranks
  tools/profile_window.sh                        # c=1 window, traces copied from both ranks
  ./stop.sh
Parse with tools/extract_kernels.py on an idle host and compare with the r3 profile
(results/2026-09-25-kernels/profile/c1). Expected per decode step, per rank:
  - DtoH(hash) -> HtoD(rows) gap: r3 median 3.06 ms (profiled) -> ~0.2-0.35 ms; the hash
    DtoH now sits before the SWA/compressor metadata chain, not after it;
  - DeviceScan / compute_cuda_kernel (token map): 21.08 -> 2 per step;
  - compare_scalar<long> + DtoD + Fill<int> of the 15 causal SWA builds: gone;
    _swa_decode_fused_kernel x15 instead of _compute_swa_indices_and_lens_kernel x15;
  - p2b prologue: _moe_prep_kernel once per MoE layer instead of ~14 single-block kernels,
    and one fp16 -> bf16 cast after p2b instead of direct_copy + bfloat16_copy;
  - _mask_candidates / _candidate_flags (4 per step): ~70.4 + 7.3 us -> ~7 us per layer;
  - indexer weights_proj: _wp_gemv_kernel (8 per step at m 2..8) instead of
    cutlass_80_wmma_tensorop_bf16_s161616gemm_bf16_16x16_128x1; the qkv join waits
    ~0.5 us after qkv_a in the +wp layers (r3: 23.8 us).
[native-census] lines: rows/call = n x 12 local heads x 2 tables (96 at n=4; about half
are owned by the rank and read), miss/call near 0 with prefetch v3 on, us/call ~150-300
at n=4 (spark2 bench: 141.7 prefetched, 274.1 hot, CPU critical path).

5. Decision (ARMS step 6)
-------------------------
Promote ALL (or a B set) only if: every B boot's prose_long c=1 median_ms_per_step beats
the A median by more than the noise (the larger of the A and B boot-to-boot spreads),
at matched acceptance (per-boot median_run_acceptance_len overlap: these levers are
bit-exact, so acceptance must not move; if it does, something is wrong -> stop and
diff); non-inferiority on pp_warm / pp_novel 8k/32k, prose_long c=2 aggregate and
warm-prefix hit fraction; quality quick exit 0; disarm scan clean on every boot;
honest cells (natural_finish_reason length, serve_env_ranks_match true).
Expected ALL vs A (round-34 reference cells): prose_long c=1 62.88 -> ~59.9-60.1 ms/step
(33.13 -> ~34.7 tok/s), L.A.I.L 33.98 -> ~35.5 tok/s, prose_long c=2 45.94 -> ~48
aggregate, all at unchanged acceptance. Prefill cells expected unchanged: prefill > 64
tokens keeps the stock Engram stage, prefill/mixed SWA builds and prefill candidate masks
are stock, and what does run at prefill sizes (MoE prep, M <= 8 GEMV) is bit-exact and
negligible there.
Rollback: unset the envs (default 0) and reboot. No image or pack change is involved.
